# Estética Rosa Bella — recursos preliminares para landing Marcabyte Start

Identidad propuesta: negro carbón #111114 (60 %), marfil rosado #F7F0F3 (30 %) y rosa empolvado #D58CAD (10 %). Valores propuestos, no medición exacta de color del logo.

## Incluye
- `brand/rosa-bella-logo-original.png`: copia intacta del archivo original aportado por el usuario. Conservar sin alterar.
- `hero/hero-desktop.webp` y `hero/hero-mobile.webp`: ilustraciones generadas por IA, sin textos superpuestos. Colocar HTML por encima de la imagen con capa/degradado para legibilidad.
- `hero/hero-spa.webp`, `hero/hero-maquillaje.webp`: imágenes ambientales alternativas.
- `services/*.webp`: nueve fotos ilustrativas para las categorías. Recortadas de un tablero generado por IA; resolución moderada para tarjetas y móvil, no para impresión ni ampliaciones.
- `services/wide/*.webp`: nueve banners de ejemplo que YA incluyen rótulos incrustados; preferir las fotos sin rótulos para HTML accesible.
- `icons/*.svg`: diecisiete iconos vectoriales con fondo transparente en estilo coherente, reemplazables y aptos para uso web; cada archivo es independiente.
- `decoration/*.webp`: dos texturas ornamentales.

## Avisos importantes
Imágenes de IA son **ilustrativas** y **NO muestran trabajos, personal, clientes, procedimientos ni instalaciones reales** de Rosa Bella. Pedir permiso al negocio para usar el logo y fotografías propias. No presentar resultados de estética clínica como prometidos. Las categorías y tratamientos concretos, horarios, tarifas y políticas de citas deben validarse antes de publicar. Este paquete contiene recursos, no una web funcional.
